# Project pages on CurseForge and Wago

The texts and images for the addon's pages on [CurseForge](https://www.curseforge.com/) and [Wago](https://addons.wago.io/addons/kNMPl3Gz). Keep them in step with the [README](../../README.md) when features change.

## Summary

The short text that shows in search results.

**CurseForge** (its moderation guidelines ask for preferably one sentence):

> Four buttons that always use the best healing potion, mana potion, food and drink in your bags.

**Wago:**

> Four buttons that always use the best healing potion, mana potion, food and drink in your bags. They keep up as you loot, fall back to your next-best potion in combat, and save your buff food for when you want it.

## Description

[description.md](description.md), for both sites. It's Markdown: on CurseForge, switch the description editor to Markdown before pasting. To copy it, open the file on GitHub and use "Copy raw file".

It follows CurseForge's moderation rules, which are the stricter of the two:

- It says what the addon adds to the game, in concrete terms.
- It has no download links to other sites. The GitHub links for bug reports and the source code are at the bottom, where CurseForge wants external links.
